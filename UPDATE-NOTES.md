- Hero keeps the same full-width fleet photograph and its existing responsive
  coverage. The introductory text, labels and buttons were removed from the hero.
- The following section now presents PV TRAVELS, Chengannur, Sabarimala travel,
  family/group travel and 4–49 seating with a 40–49-seat group highlight. It uses
  the existing colours, fonts and WhatsApp/Call buttons.
- The old ROOTED IN CHENGANNUR content, image, statistics and enquiry link were

  the existing navigation.
- Three pickup cards appear after Sabarimala route pagination and before the
  existing temple journey cards: Thiruvananthapuram, Kollam and Kottayam.

  details”; no distance or duration was invented.
- Existing route names and distances, fleet, gallery, form, footer, telephone
  and WhatsApp number are retained. The pre-existing repeated Ettumanoor card
  is retained; React keys now distinguish repeated entries safely.

## SEO and performance

The server layout provides the requested homepage title and description,
canonical URL, Open Graph/Facebook/WhatsApp metadata, X/Twitter metadata and
Google image/snippet preview settings. The introductory heading is the single
H1. The new card headings describe the pickup areas naturally.

JSON-LD describes LocalBusiness, WebSite, WebPage and the transport Service,
using the existing name, telephone, email, map link and locality. It contains no
invented street address, prices, hours, reviews or ratings. The graph is parsed
successfully from the exported HTML. The homepage is the only public content
page, so its sitemap contains one URL; anchors are not separate pages.

Static-export-compatible robots and sitemap files use the same configured
production domain as canonical and sharing metadata. No SEO package was added.

The hero uses eager high-priority loading, explicit dimensions and responsive
WebP derivatives. The desktop 1920px derivative is about 443 KB versus the
original 2.26 MB; the 640px derivative is about 93 KB. The original photograph
is unchanged. Pickup photos use lazy loading and responsive sources, with
fixed image frames to reserve space. The Vaikom photo retains the uploaded
736 × 1308 resolution; no artificial upscaling was used. System fonts and
existing animations remain in place.

Core Web Vitals and Google rankings were not measured or guaranteed.

## Domain and environment

Default production origin: `https://www.pvtravelschengannur.com`, taken from the
original project. No new environment variable is required for that domain.

If the real preferred origin changes, create `.env.local` beside `package.json`:

```env
NEXT_PUBLIC_SITE_URL=https://your-real-domain.com
```

Use an absolute HTTPS origin without a path. Set the same variable in your
hosting build environment, then rebuild. Configure redirects for alternate
www/non-www domains in your hosting dashboard. Keep a single preferred origin.
